# Изображения за тренировъчните упражнения

Свързани са 39 от 57 упражнения в текущата библиотека по съществуващия им код. Локалните кадри са от Workout Guide на Bryl Lim, базиран на изображения на Everkinetic, под CC BY-SA 4.0. [Лиценз и авторство](https://github.com/bryllim/workout-guide/blob/main/ATTRIBUTION.md)

За липсващите кадри използвай следващата таблица. Заснеми или нарисувай начална и крайна позиция според инструкциите и оборудването в `src/main/resources/content/exercises.json`. При статично упражнение е достатъчен един кадър. Записвай във `static/images/exercises/` като `<code>-start.webp` и `<code>-finish.webp` или `<code>-hold.webp`.

| Код | Упражнение |
| --- | --- |
| `reverse-lunge` | Обратен напад |
| `calf-raise` | Повдигане за прасци |
| `step-up` | Качване на платформа |
| `chest-fly` | Флайс с дъмбели |
| `barbell-curl` | Бицепсово сгъване с щанга |
| `side-plank` | Страничен планк |
| `crunch` | Коремни преси |
| `fast-walk` | Бързо ходене |
| `stepper` | Степер |
| `hip-hinge` | Тазобедрено сгъване |
| `thoracic-rotation` | Ротации на гръден отдел |
| `hip-90-90` | Преходи 90/90 за таз |
| `ankle-mobility` | Мобилизация на глезен |
| `chair-squat` | Клек до стол |
| `backpack-row` | Гребане с раница |
| `backpack-press` | Раменна преса с раница |
| `knee-side-plank` | Страничен планк от колене |
| `narrow-wall-push-up` | Тясна лицева опора от стена |

Упражненията в лични програми без връзка с библиотеката показват запазените си указания, серии, повторения и почивка.
