# Изображения за тренировъчните упражнения

Свързани са всички 57 упражнения в текущата библиотека по съществуващия им код. Кадрите за първите 43 упражнения са от Workout Guide на Bryl Lim, базиран на изображения на Everkinetic, под CC BY-SA 4.0. [Лиценз и авторство](https://github.com/bryllim/workout-guide/blob/main/ATTRIBUTION.md)

За следващите 14 упражнения са добавени нови илюстрации, генерирани за FitPulse по техниката и оборудването в `src/main/resources/content/exercises.json`. Те са локални 420×420 WebP файлове с бели контури върху прозрачен фон. Динамичните упражнения имат два кадъра (`<code>-start.webp` и `<code>-finish.webp`). Степерът и страничният планк от колене имат по един представителен кадър (`<code>-hold.webp`).

| Код | Упражнение |
| --- | --- |
| `reverse-lunge` | Обратен напад |
| `step-up` | Качване на платформа |
| `crunch` | Коремни преси |
| `fast-walk` | Бързо ходене |
| `stepper` | Степер |
| `hip-hinge` | Тазобедрено сгъване |
| `thoracic-rotation` | Ротации на гръден отдел |
| `hip-90-90` | Преходи 90/90 за таз |
| `ankle-mobility` | Мобилизация на глезен |
| `chair-squat` | Клек до стол |
| `backpack-row` | Гребане с раница |
| `backpack-press` | Раменна преса с раница |
| `knee-side-plank` | Страничен планк от колене |
| `narrow-wall-push-up` | Тясна лицева опора от стена |

Упражненията в лични програми без връзка с библиотеката показват запазените си указания, серии, повторения и почивка.
